    Without the box

    If the Pi runs but there is no LIBRARY Wi-Fi: plug a laptop into the Pi's Ethernet port with a cable, set the wired connection to address 10.10.10.20, netmask 255.255.255.0, and open http://10.10.10.10 (the name library.lan does not work this way). Without the Pi: a laptop running Linux can read the backup SSD; open the library folder on it, then index_v1.html, the plain version of this page. Mac and Windows laptops cannot read that SSD without extra software. PDFs, plant photos and website copies open as files; the encyclopedias (.zim files) need the Kiwix program in tools/kiwix_desktop/, or the Kiwix app from tools/android/ on an Android phone. Full steps: Operator runbook, Part 2, step 4.

    This library's own pages, summaries and search never state drug doses. The medical books on the shelf do: use the printed drug guide (Davis's, Lippincott pocket) for any dose. A wrong table kills; paper from a licensed publisher doesn't go stale silently.
