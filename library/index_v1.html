Offline Survival Library

About 1.3 TB, all on this drive, no internet needed. This page has no scripts and works in any browser, opened from the drive or from the box. Two kinds of content:

  • Direct links below: PDFs and mirrored websites, open right here. Links ending in / open a folder listing; from a drive that needs Chrome or Firefox (Safari cannot list folders).
  • [Kiwix] items: ZIM archives in zim/. On the box they are at library.lan:8080; from a drive, open them in the Kiwix app.
🚑 Medical emergency? Open SYMPTOM TRIAGE — it routes you to the right document fast.

Without the box

If the Pi runs but there is no LIBRARY Wi-Fi: plug a laptop into the Pi's Ethernet port with a cable, set the wired connection to address 10.10.10.20, netmask 255.255.255.0, and open http://10.10.10.10 (the name library.lan does not work this way). Without the Pi: a laptop running Linux can read the backup SSD; open the library folder on it, then index_v1.html, this page. Mac and Windows laptops cannot read that SSD without extra software. PDFs, plant photos and website copies open as files; folders ending in / list in Chrome or Firefox (Safari cannot). The encyclopedias (.zim files in zim/) need the Kiwix program in tools/kiwix_desktop/, or the Kiwix app from tools/android/ on an Android phone. Full steps: RUNBOOK, Part 2, step 4.
