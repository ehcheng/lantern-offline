# LibriVox Audiobook Collection

Public-domain audiobooks downloaded from LibriVox via archive.org.
All files are 64 kbps MP3.
Total: 52 books, 1,600 sections, 14.0 GB (13.1 GiB) at 64 kbps (measured 2026-10-09).

Section titles shown in the player come from the archive.org metadata for each recording.
The download kept every file of 100 KiB or more that starts with an MP3 header; an earlier 1 MiB floor had silently dropped 37 short sections (32 Aesop fables,
two Beatrix Potter tales, the Oz and Anne of Green Gables introductions and the last Oz chapter). They were
restored on 2026-10-09.
