The box works, but the library isn't loaded yet

This Lantern box started fine, but its data partition is empty.

To load it, plug the backup SSD (the Samsung T5, a palm-sized silver drive; its partition is named LANTERN_BAK) into one of the Pi's blue USB ports, log in over ssh as lantern, and copy the library over. It takes 1 to 2 hours over USB 3 for 1.3 TB:

sudo mkdir -p /mnt/bak
mountpoint -q /mnt/bak || sudo mount -L LANTERN_BAK /mnt/bak
sudo rsync -aH --info=progress2 /mnt/bak/library/ /data/library/
cd /data && sha256sum -c --quiet library/MANIFEST.sha256 && echo all files OK
sudo umount /mnt/bak

The first two lines make the folder /mnt/bak and attach the SSD there; if the SSD is already attached, the second line does nothing. The check on the fourth line reads every file and takes 1.5 to 2 hours. It prints nothing until it ends, so a quiet screen does not mean it has stopped. These are the same steps as the printed RUNBOOK, Part 3, "Rebuilding from nothing", step 4.

When the copy finishes, restart the box. This page is replaced by the library front page.
